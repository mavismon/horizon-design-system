## Other findings (outside the gates)

- **`item1Href`, `item2Href` and `item3Href` are not Figma properties.** Figma's design context for 163:2 lists only `className`, `current`, `item1`, `item2`, `item3`, `showItem2`, `showItem3`. The three optional href props were added by the engineer so that ancestors have destinations (the QA report says so). They are optional, so with none set, an ancestor renders `<a className="hz-breadcrumbs__link">` with no `href`, which is not a link: it is not focusable and is not announced as a link. Figma Best Practice `163:186` ("Make every item except the current page a link to that page") therefore depends on the consumer passing the hrefs: the component does not enforce it. The fourth `a11y` fact ("Each ancestor is a native `<a>`, so keyboard focus, the focus ring and activation are the browser's own") holds only when an href is passed. The stories pass `"#"` for all three, so every story shows links. Owner: engineer or designer, to decide whether the hrefs should be required, or documented, or whether Figma should gain a link property.
- **Best Practice `163:210` is covered by the code** (`nav` landmark, `aria-label="Breadcrumb"`, `aria-current="page"` on the last item; `Breadcrumbs.tsx:36`, `:49`). `163:198` (current page darker, not a link) is covered by `Breadcrumbs.css:30-32` and `Breadcrumbs.tsx:49`. `163:204` (don't wrap) is covered by `white-space: nowrap` (`Breadcrumbs.css:6`). `163:192` (use the same names as page titles) is content guidance for the consumer.
- **Usage line `163:158` ("Show 2 to 4 levels; hide unused levels with ShowItem2 and ShowItem3")** uses Figma's property casing. The React props are `showItem2` and `showItem3`. A consumer reading the docs page sees `ShowItem2`. Noted only.
