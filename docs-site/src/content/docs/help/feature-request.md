---
title: Request a feature
description: How to ask for a new component, prop or token.
---

Open an issue on [GitHub](https://github.com/mavismon/horizon-design-system/issues/new) saying what you need and what you'd use it for.

A new component starts in Figma: it's designed there, then built, tested, deployed and reviewed before it gets a page on this site. The [Roadmap](/get-started/roadmap/) shows the components already on the registry.
