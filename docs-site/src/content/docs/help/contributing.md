## Where changes land

The repository is [mavismon/horizon-design-system](https://github.com/mavismon/horizon-design-system). Changes are merged into `main` through pull requests from the `staging` branch.

## A component's path

Each component moves through the same steps, tracked on the team's registry:

1. It's designed in Figma, with a Usage frame.
2. It's built in `src/components/<Name>/`: the component, its stylesheet (tokens only), its stories and its intent file.
3. It's tested against its Figma node, then deployed to the production Storybook.
4. It clears a release review, which checks its tokens, public surface, names, states, intent file and the versioning policy.
5. It gets a page on this site, generated from the reviewed commit.

## Working on the code

```bash
npm install
npm run storybook       # builds the tokens, then starts Storybook on port 6006
npm test                # builds the package, then runs the tests in test/
```

`npm run build:package` builds the tokens, the library (`tsup`) and the two stylesheets into `dist/`.

## Working on this site

The site is the `docs-site/` folder on the `astro` branch. Reference pages are generated by `docs-site/scripts/generate.mjs`; change the source or the script, never a generated page.
