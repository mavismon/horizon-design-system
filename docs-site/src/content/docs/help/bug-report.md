---
title: Report a bug
description: How to report something that's broken.
---

Open an issue on [GitHub](https://github.com/mavismon/horizon-design-system/issues/new). Include:

- the package version (from your `package.json` or `npm ls @layerbasesystemic/horizon-design-system`);
- the component and the props you passed;
- what you expected, what happened instead, and how to make it happen;
- the theme (`data-theme`) and browser, if it's visual.

If the component doesn't match its Figma design, name the Figma node from the header of its page here.
