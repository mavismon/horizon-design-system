## When to use it

- To show the signed-in user's profile photo, such as in the header.
- To represent a person (a host, guest or reviewer) next to their name or content.
- Use md (30px) in the header, sm (24px) in dense lists or inline with text, and lg (40px) where the person is the focus, such as a profile or message thread.

## When not to use it

- For brand or company logos: use the Logo component instead.<br/>**Instead:** Logo
- For listing or content photos: use the Image component instead.<br/>**Instead:** Image
- As a clickable control on its own: place it inside a Button or Link so it has an accessible name.<br/>**Instead:** Button or Link

## Best practice

From the Figma documentation page (usage node `113:7`), as written. These items aren't carried into `Avatar.intent.json`, which has no field for them.

- Crop photos square with the face centred; the circle clips the corners.
- Keep one avatar size within the same list or row.
- Give the image alt text with the person's name, or leave it empty when the name is shown right beside it.
- Use only the sm, md and lg sizes; don't scale an avatar to other sizes.
- Always supply a photo. There's no fallback for a missing photo yet.

## Accessibility

- The photo is a native &lt;img&gt; whose alt text comes from the alt prop, defaulting to an empty string (decorative). [`src/components/Avatar/Avatar.tsx:21`](https://github.com/mavismon/horizon-design-system/blob/b9ffb76f7673fe33ddc04617d587557e93084f96/src/components/Avatar/Avatar.tsx#L21)

## Design gaps recorded against it

- **2026-10-01 · Avatar diameters with no token** ([decisions.md](https://github.com/mavismon/horizon-design-system/blob/b9ffb76f7673fe33ddc04617d587557e93084f96/decisions.md)). These literals in src/components/Avatar/Avatar.css are accepted, because they're what the Figma node specifies (node 113:2, component 112:9), until the designer adds avatar size tokens. Accepted values: `24px` (width, height on .hz-avatar--sm, lines 13, 14); `30px` (width, height on .hz-avatar--md, lines 18, 19); `40px` (width, height on .hz-avatar--lg, lines 23, 24). *Not ruled:* Any other literal value, including a var() fallback. These values in any other component. A change to these values: a different number needs a new ruling or a token.
