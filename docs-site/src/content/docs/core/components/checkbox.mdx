## When to use it

- To let the user opt in to something, such as marketing emails or staying signed in.
- To confirm the user has read and agreed to terms before they continue, such as the booking terms or cancellation policy.
- To make the user acknowledge a destructive action before it runs, using the error state (for example, "I understand this is permanent").
- For a list of options where the user can choose any number, such as search filters.

## When not to use it

- For a setting that takes effect immediately: use the Toggle component instead.<br/>**Instead:** Toggle
- When the user must pick exactly one option from a list: use the Radiocard component instead.<br/>**Instead:** Radiocard
- To trigger an action: use the Button component instead.<br/>**Instead:** Button

## Best practice

From the Figma documentation page (usage node `118:10`), as written. These items aren't carried into `Checkbox.intent.json`, which has no field for them.

- Always give the checkbox a visible label that says what ticking it does.
- Write labels as positive statements ("Email me deals"), not negatives ("Don't email me").
- Leave opt-in checkboxes unticked by default.
- Make the whole label clickable, not just the 16px box.
- Use the error state only for acknowledging destructive or irreversible actions.
- Put extra detail in helper text below the label, not in the label itself.

## Accessibility

- The control is a native &lt;input type="checkbox"&gt;, so keyboard, focus and disabled behaviour are the browser's own. [`src/components/Checkbox/Checkbox.tsx:19`](https://github.com/mavismon/horizon-design-system/blob/eb7adcdaa1626b154435b47400174490706c2fed/src/components/Checkbox/Checkbox.tsx#L19)
- The input and label text sit inside one &lt;label&gt;, so clicking the label text toggles the checkbox and gives it its accessible name. [`src/components/Checkbox/Checkbox.tsx:17`](https://github.com/mavismon/horizon-design-system/blob/eb7adcdaa1626b154435b47400174490706c2fed/src/components/Checkbox/Checkbox.tsx#L17)
- The tick is a decorative SVG hidden from assistive technology (aria-hidden); the checked state is carried by the native input. [`src/components/Checkbox/Checkbox.tsx:24`](https://github.com/mavismon/horizon-design-system/blob/eb7adcdaa1626b154435b47400174490706c2fed/src/components/Checkbox/Checkbox.tsx#L24)
