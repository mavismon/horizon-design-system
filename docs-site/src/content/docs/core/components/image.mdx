## When to use it

- To show a photo of a listing, room or place, such as the photo at the top of a property card or the photos in a listing gallery.
- Use radius none for a photo that runs edge to edge inside a card; the card rounds the corners.
- Use radius md (12px) for standalone photos such as the gallery and marketing tiles, and radius sm (6px) for small thumbnails in lists.
- Use 16:9 for wide gallery and hero photos, 3:2 for property cards, 4:3 or 1:1 for thumbnails, and 2:1 for banners and marketing tiles.

## When not to use it

- For a person's profile photo: use the Avatar component instead.<br/>**Instead:** Avatar
- For the Horizon Stays brand mark: use the Logo component instead.<br/>**Instead:** Logo
- For icons or small symbols: use an icon from the Icon Library instead.<br/>**Instead:** Icon Library

## Best practice

From the Figma documentation page (usage node `125:2`), as written. These items aren't carried into `Image.intent.json`, which has no field for them.

- Choose the ratio first, then resize by width; the ratio is locked, so photos never stretch.
- Crop the photo to fill the frame; don't letterbox or distort it.
- Keep one ratio and radius across a group, such as every card in a results list.
- Give every meaningful image alt text that describes it; leave alt text empty for purely decorative images.
- Show the placeholder while a photo loads, in the same ratio, so the layout doesn't jump.

## Accessibility

- The component renders a native &lt;img&gt;, so loading, decoding and alt behaviour are the browser's own and every &lt;img&gt; attribute (loading, srcSet, sizes) passes through. [`src/components/Image/Image.tsx:34`](https://github.com/mavismon/horizon-design-system/blob/eb7adcdaa1626b154435b47400174490706c2fed/src/components/Image/Image.tsx#L34)
- alt defaults to an empty string (decorative) and is overridden by the alt prop. [`src/components/Image/Image.tsx:29`](https://github.com/mavismon/horizon-design-system/blob/eb7adcdaa1626b154435b47400174490706c2fed/src/components/Image/Image.tsx#L29)
- The photo is cropped to the frame with object-fit: cover, so it is never stretched. [`src/components/Image/Image.css:5`](https://github.com/mavismon/horizon-design-system/blob/eb7adcdaa1626b154435b47400174490706c2fed/src/components/Image/Image.css#L5)
