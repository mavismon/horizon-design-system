## When to use it

- Use type section for a form inside a page, such as Profile, payment details or back office settings, with a Save changes and Cancel group at the end.
- Use type card for a short form on its own, such as Sign in, Create your account or Invite someone, with one full-width button.
- Build every input from textfield; use Dropdown, Checkbox, Radiocard or Toggle in the same stack when a field is a choice.
- Label every field above the input, and keep placeholders for examples, never for the label.
- Show an error under the field that caused it and say how to fix it, such as "Use a full email address"; keep what the person typed.
- Ask only for what you need, in the order people think about it, and put the main action last.

## When not to use it

- For one setting that applies at once: use a Toggle, without a Save button.<br/>**Instead:** Toggle
- To search or filter a list: use Searchbar or Chip filters.<br/>**Instead:** SearchBar
- For a long flow such as booking: split it into steps with Stepper type progress.<br/>**Instead:** Stepper
