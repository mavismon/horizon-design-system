## When to use it

- At the end of a dialog or form, to pair the main action with a way out, such as "Publish review" and "Save as draft", or "Save role and access" and "Cancel".
- Use type destructive when the main action deletes or cancels something, such as "Continue to cancel" and "Keep my booking".
- Use type secondary for two actions of equal weight, such as "View" and "Modify" on a trip card.
- Use layout stack on narrow screens such as the mobile app, with the main action on top.
- Use type segmented to switch a view between 2 to 4 options, such as the time range "Last 24 hours / 7 days / 30 days / Custom range" on the back office dashboard. Exactly one segment is selected.

## When not to use it

- For a single action: use the Button component instead.<br/>**Instead:** Button
- To filter a list by several values at once: use the Chip component instead. Segments pick exactly one option.<br/>**Instead:** Chip
- For more than three actions, or more than four segments: move the extras into a Dropdown component.<br/>**Instead:** Dropdown

## Best practice

From the Figma documentation page (usage node `193:59`), as written. These items aren't carried into `ButtonGroup.intent.json`, which has no field for them.

- Put the main action first: on the left in a row, on top in a stack.
- Use at most one filled button per group; the others are outline.
- Label buttons with what they do ("Delete account", "Keep my account"), not "Yes" and "No".
- Keep the whole group together; don't split its buttons across the layout.
- In a destructive group, make the safe choice easy to find and never the filled button.

`--color-primary-default`, `--color-status-error` hold a different value in Figma from the token of the same name in the build. `ButtonGroup.css` doesn't read those tokens, but the stylesheet of the component ButtonGroup is built from does ([`Button.css`](https://github.com/mavismon/horizon-design-system/blob/c77c53b6288a1992c22e73fe6fb32f66e43d304d/src/components/Button/Button.css)), so the Button rendered inside ButtonGroup uses the build's value, not Figma's.
