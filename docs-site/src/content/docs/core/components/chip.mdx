## When to use it

- To filter a list of results, such as search filters ("Pool", "Pet friendly", "Free cancellation").
- To switch between categories of the same content, such as "All", "Bedrooms" or "Kitchen" in a photo gallery.
- Use the selected state (blue) for filters the user has turned on, and selected-strong (navy) for the active category in a category row.
- To show how many items an option holds, as part of the label (for example, "Kitchen 6").

## When not to use it

- To show a status such as "Confirmed" or "Pending": use a Badge component instead.<br/>**Instead:** Badge
- To trigger an action, such as booking or submitting: use the Button component instead.<br/>**Instead:** Button
- For a yes or no choice inside a form: use the Checkbox component instead.<br/>**Instead:** Checkbox
- To go to another page: use the Link component instead.<br/>**Instead:** Link

## Best practice

From the Figma documentation page (usage node `122:336`), as written. These items aren't carried into `Chip.intent.json`, which has no field for them.

- Keep labels short: one to three words, plus an optional count.
- A chip that's on must use a selected state, so the current selection is always visible.
- Don't mix selected and selected-strong chips in the same row.
- Space chips 8px apart in one row; let the row scroll or wrap on small screens rather than shrinking the chips.
- When several filters can be on at once, give the user a way to clear them all.
- Mark the selected chip for assistive technology (aria-pressed or aria-selected), not with colour alone.

## Accessibility

- The control is a native &lt;button type="button"&gt;, so keyboard activation, focus ring and disabled behaviour are the browser's own. [`src/components/Chip/Chip.tsx:19`](https://github.com/mavismon/horizon-design-system/blob/6cd06429f5ab43324cca65077f196ebf81891fe1/src/components/Chip/Chip.tsx#L19)
- The selected state is exposed to assistive technology through aria-pressed (true for selected and selected-strong, false for unselected), and a caller-supplied aria-pressed overrides it because the passthrough props are spread after it. [`src/components/Chip/Chip.tsx:21`](https://github.com/mavismon/horizon-design-system/blob/6cd06429f5ab43324cca65077f196ebf81891fe1/src/components/Chip/Chip.tsx#L21)
- The label is the button's text content, which gives it its accessible name. [`src/components/Chip/Chip.tsx:25`](https://github.com/mavismon/horizon-design-system/blob/6cd06429f5ab43324cca65077f196ebf81891fe1/src/components/Chip/Chip.tsx#L25)
