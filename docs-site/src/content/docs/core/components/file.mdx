## When to use it

- Use type dropzone where people add files: attachments in messages and support requests, room photos and verification documents in the back office.
- Use type item for each file once it is added, in a list under the drop zone, with its name, type and size.
- Show state uploading with the progress while a file is sending, and state error with the reason when a file is refused.
- Put the accepted types and the size limit in the Hint, such as "PDF, JPG or PNG · 10 MB each".
- Say what went wrong and how to fix it in the error, such as "Too large: the limit is 10 MB".
- Keep the whole drop zone clickable, so "browse" works without dragging, on touch screens too.

## When not to use it

- To show a document people download but never upload, such as a receipt or invoice: use a Link or a table row.<br/>**Instead:** Link, table row
- For a profile photo: use Avatar with its own upload action.<br/>**Instead:** Avatar
- Do not hide the limits: never leave the Hint empty.<br/>*The Figma page names no alternative.*

## Accessibility

- The dropzone is a &lt;label&gt; wrapping a native &lt;input type="file"&gt; (visually the whole zone), so clicking anywhere on it, or Tab then Enter/Space, opens the browser's file picker and works on touch without dragging. [`src/components/File/File.tsx:121`](https://github.com/mavismon/horizon-design-system/blob/1fd601d7afde2850d6ec8304c9e7d015487dc819/src/components/File/File.tsx#L121)
- The file input is described by the hint text (aria-describedby), so accepted types and size limit are announced with it. [`src/components/File/File.tsx:137`](https://github.com/mavismon/horizon-design-system/blob/1fd601d7afde2850d6ec8304c9e7d015487dc819/src/components/File/File.tsx#L137)
