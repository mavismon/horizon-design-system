## When to use it

- At the left of the header on every page, using the lockup at 32px high.
- Use the mark on its own where there's no room for the wordmark, such as a collapsed sidebar, an app icon or a favicon.

## When not to use it

- For listing, room or place photos: use the Image component instead.<br/>**Instead:** Image
- For a person's profile photo: use the Avatar component instead.<br/>**Instead:** Avatar
- As a decorative icon or bullet: use an icon from the Icon Library instead.<br/>**Instead:** Icon Library

## Best practice

From the Figma documentation page (usage node `137:506`), as written. These items aren't carried into `Logo.intent.json`, which has no field for them.

- Use the logo as it is: don't recolour, stretch, rotate or add effects to it.
- Scale an instance proportionally only (hold Shift while resizing); never change its width and height separately.
- Don't edit the wordmark text or retype it in another font.
- Leave clear space around the logo; don't crowd it with other elements.
- Place it on a light background so the blue stays readable; there's no version for dark backgrounds yet.
- Don't show the mark and the lockup side by side on the same screen.

## Accessibility

- The mark is a native &lt;img&gt;. Its alt defaults to an empty string in the lockup, where the wordmark text beside it names the logo, and to "Horizon Stays" in the mark-only variant; the alt prop overrides either. [`src/components/Logo/Logo.tsx:14`](https://github.com/mavismon/horizon-design-system/blob/b9ffb76f7673fe33ddc04617d587557e93084f96/src/components/Logo/Logo.tsx#L14)
- The mark image carries explicit width and height of 32, its intrinsic size. [`src/components/Logo/Logo.tsx:20`](https://github.com/mavismon/horizon-design-system/blob/b9ffb76f7673fe33ddc04617d587557e93084f96/src/components/Logo/Logo.tsx#L20)

## Themes

The Logo frame renders both variants once, in one theme, and has no separate light and dark frames. The mark is the committed SVG asset (src/assets/images/logo-mark.svg) with its colours fixed inside the file, and the wordmark colour is a fixed literal in the stylesheet, so neither follows the UI theme tokens and the Logo does not change between light and dark. Figma's Best Practice says there's no version for dark backgrounds yet.

The token build defines 179 tokens for light and redeclares 50 for dark; the Code tab shows Logo's tokens in both.
