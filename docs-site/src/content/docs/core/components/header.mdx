## When to use it

- Use type web at the top of every page of the guest website, with the current section as the first, darker link.
- Use type app at the top of each app screen below the status bar: back on the left, the screen name in the centre, one text action on the right when the screen has one, such as "Save" or "Mark read".
- Use type backoffice above the content of each back office page, next to the Sidebar, with the page name and search.
- Keep the app title short (one or two words) so it stays centred and never truncates.
- Turn ShowAvatar off for signed-out guests on web; the Book now button stays.
- Hide the back chevron (ShowBack off) only on the top-level tabs of the app, such as Explore or Trips.

**Property names.** Item 5 is copied from Figma as written, with Figma's spelling of the properties. The code spells it [`showAvatar`](https://github.com/mavismon/horizon-design-system/blob/5e1cd6b400415376962fab69351c5fa8f7cb3aee/src/components/Header/Header.tsx#L21).

**Property names.** Item 6 is copied from Figma as written, with Figma's spelling of the properties. The code spells it [`showBack`](https://github.com/mavismon/horizon-design-system/blob/5e1cd6b400415376962fab69351c5fa8f7cb3aee/src/components/Header/Header.tsx#L25).

## When not to use it

- More than once on a page, or inside a card or a modal.<br/>*The Figma page names no alternative.*
- To hold page actions such as "Export" or "Add rate": put them in the page content, under the title.<br/>*The Figma page names no alternative.*
- With more than three nav links on web: move the rest into the Help page or the footer.<br/>*The Figma page names no alternative.*

**No alternative named.** All 3 items above have an empty `instead` in `Header.intent.json`. From the [release review](https://github.com/mavismon/horizon-design-system/blob/20bfa3c3bd9349e183a4e293256084965dd14447/reports/Header/release-review.md), under "Warnings (not blocking)", as written:

The frame names no alternative component (entries 2 and 3 name a place, not a component).
