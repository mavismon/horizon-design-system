## When to use it

- To pick one value from a list of five or more, such as the property filter "All properties" on the back office calendar, or "Who" in the activity log filters.
- Use size md (36px) in forms and for the sort control on search results; use size sm (30px) in compact filter bars and table headers.
- Show the label above the field in forms. Hide it (ShowLabel off) only when the value says what it is, such as "Sort: Price, low first".
- Always show a value in the field: the current choice or a neutral default such as "All properties". Never leave it blank.
- Order options in a way people expect: by frequency, by time, or alphabetically, and put "All" first.
- Keep option text short enough for one line at the field's width.

**Property names.** Item 3 (Figma node `200:37`) is copied from Figma as written, with Figma's spelling of the properties. The code spells it [`showLabel`](https://github.com/mavismon/horizon-design-system/blob/c77c53b6288a1992c22e73fe6fb32f66e43d304d/src/components/Dropdown/Dropdown.tsx#L14).

## When not to use it

- For two to four options that should stay visible: use Buttongroup type segmented, or Radiocard.<br/>**Instead:** ButtonGroup (type segmented), Radiocard
- To pick several values at once: use Chip filters or Checkboxes instead.<br/>**Instead:** Chip, Checkbox
- For actions such as "Export" or "Delete": use Button, or a Buttongroup.<br/>**Instead:** Button, ButtonGroup

## Accessibility

- The field is a native &lt;button type="button"&gt; with aria-haspopup="listbox", so focus and disabled behaviour are the browser's own. [`src/components/Dropdown/Dropdown.tsx:145`](https://github.com/mavismon/horizon-design-system/blob/c77c53b6288a1992c22e73fe6fb32f66e43d304d/src/components/Dropdown/Dropdown.tsx#L145)
- aria-expanded reflects whether the menu is open, and aria-controls points at the listbox only while it is open. [`src/components/Dropdown/Dropdown.tsx:149`](https://github.com/mavismon/horizon-design-system/blob/c77c53b6288a1992c22e73fe6fb32f66e43d304d/src/components/Dropdown/Dropdown.tsx#L149)
- With the label shown, the button is named by the label and its own value (aria-labelledby); with showLabel off, the label text is kept as aria-label. [`src/components/Dropdown/Dropdown.tsx:152`](https://github.com/mavismon/horizon-design-system/blob/c77c53b6288a1992c22e73fe6fb32f66e43d304d/src/components/Dropdown/Dropdown.tsx#L152)
- The open menu is a role="listbox" named by the label (aria-labelledby, or aria-label when the label is hidden). [`src/components/Dropdown/Dropdown.tsx:163`](https://github.com/mavismon/horizon-design-system/blob/c77c53b6288a1992c22e73fe6fb32f66e43d304d/src/components/Dropdown/Dropdown.tsx#L163)
- Each option is a role="option" with aria-selected, and the keyboard-active option is exposed through aria-activedescendant on the button. [`src/components/Dropdown/Dropdown.tsx:168`](https://github.com/mavismon/horizon-design-system/blob/c77c53b6288a1992c22e73fe6fb32f66e43d304d/src/components/Dropdown/Dropdown.tsx#L168)
- Keyboard: ArrowDown/ArrowUp open the menu and move the active option, Home/End jump to the first/last, Enter or Space choose, Escape closes, and Tab closes; focus returns to the button after choosing. [`src/components/Dropdown/Dropdown.tsx:89`](https://github.com/mavismon/horizon-design-system/blob/c77c53b6288a1992c22e73fe6fb32f66e43d304d/src/components/Dropdown/Dropdown.tsx#L89)
