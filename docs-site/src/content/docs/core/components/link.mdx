## When to use it

- To take the user to another page or view, such as "Show all 24 amenities" or "Forgot your password?".
- For a secondary action next to a form, such as "Resend code" or "Use a different email address".
- To edit or manage an item in a list, such as "Edit" or "Manage" in account settings.
- Use size md (13px) next to body text and on its own, and size sm (12px) in dense rows, such as "Clear" beside filters.

## When not to use it

- For the main action on a page, such as submitting a form or booking: use the Button component instead.<br/>**Instead:** Button
- To filter results or switch categories: use the Chip component instead.<br/>**Instead:** Chip
- To open a list of options to choose from: use the Dropdown component instead.<br/>**Instead:** Dropdown

## Best practice

From the Figma documentation page (usage node `134:446`), as written. These items aren't carried into `Link.intent.json`, which has no field for them.

- Write link text that says where it goes or what it does ("Show all 24 amenities"), never "click here".
- Keep links short, usually one to five words.
- Underline a link that sits inside a sentence of body text, so it doesn't rely on colour alone; standalone links can use the default style.
- Use the same link text for the same destination everywhere.
- Leave space or a separator between two links next to each other.
- Make sure every link shows a visible keyboard focus style.

## Accessibility

- The control is a native &lt;a&gt;, so keyboard focus, the focus ring, activation and :visited behaviour are the browser's own; no focus style is overridden. [`src/components/Link/Link.tsx:22`](https://github.com/mavismon/horizon-design-system/blob/9344828d09f206c4c2ccc99c6110dbc63e84a59a/src/components/Link/Link.tsx#L22)
- href, target, rel and every other anchor attribute pass through because the passthrough props are spread onto the element. [`src/components/Link/Link.tsx:29`](https://github.com/mavismon/horizon-design-system/blob/9344828d09f206c4c2ccc99c6110dbc63e84a59a/src/components/Link/Link.tsx#L29)
- The label is the anchor's text content, which gives it its accessible name. [`src/components/Link/Link.tsx:31`](https://github.com/mavismon/horizon-design-system/blob/9344828d09f206c4c2ccc99c6110dbc63e84a59a/src/components/Link/Link.tsx#L31)
